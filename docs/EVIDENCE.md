## Testing quadrants
Q1: JUnit service and repository checks supporting development.
Q2: Acceptance criteria and automated Selenium workflows.
Q3: Exploratory usability checks and sprint review feedback.
Q4: Reliability/restart checks, invalid input and basic response checks.
State what was actually tested and what remains planned.

## Metrics and risks
Track date, total scope points, completed points and remaining points.
Velocity is fully completed story points per sprint; do not count parent and
subtask estimates twice. Explain scope changes and incomplete work honestly.
Keep a burndown or burnup chart per sprint (manual is allowed).
Risks: integration delays, lost data, missing evidence, environment differences.
Record likelihood, impact, mitigation, owner and actual outcome.

## Final report
Product goal/backlog; roles and events; both sprint backlogs and charts;
design/SOLID examples; two TDD modules; scripts/results; CI run; reviews;
metrics interpretation; risks; prototype instructions and limitations.
Prepare one spiral-bound group report and a working prototype presentation.
